**Массовое хранение предметов, переосмысленное как плагин для Paper.** Храните миллионы предметов в одном блоке, объединяйте их в беспроводную mesh-сеть и доставайте что угодно откуда угодно — без модов и установки клиента. Вдохновлено Applied Energistics 2.

Каждая стойка (Server Rack / DSU) хранит своё содержимое в NBT предметов, поэтому при перезапуске ничего не теряется. Поставьте Server Rack, добавьте один-два Wireless Router, повесьте терминал на стену — и всё хранилище вашей базы превращается в единую сортируемую сетку с автоматизацией через воронки.

---

## Оборудование

Enigma Storage построен вокруг нескольких физических блоков, которые вы ставите, связываете и разворачиваете в сеть.

### Server Rack (Стойка)
Ядро вашего хранилища. Вставьте ячейки памяти, добавьте доверенных игроков и подключите воронки для полностью автоматического ввода/вывода. Каждая стойка проецирует вокруг себя **зону mesh-сети в 16 блоков** — основу вашей сети.

### Wireless Router (Беспроводной роутер)
Нужно больше радиуса? Поставьте Wireless Router. Он расширяет mesh **кубом покрытия в 64 блока** и подключается к уже существующей сети — поставьте его так, чтобы его зона пересекалась с зоной стойки, и радиус будет расти органично по всей базе. Свяжите достаточно роутеров — и масштабируйте сеть на всю базу.

### Wall Terminal (Настенный терминал)
Плоский терминал, который крепится прямо на стену. Подойдите, откройте его и просматривайте содержимое привязанной стойки на месте — идеально для аккуратной, обшитой панелями комнаты-хранилища.

### Wireless Terminal (Беспроводной терминал)
Та же сетка хранилища, но в вашем хотбаре. Привяжите его модулем связи (Link Module) и получайте доступ к стойке из любой точки внутри mesh-сети — копайте, сражайтесь, стройте и складывайте добычу, не возвращаясь домой.

## Возможности

**Хранилище**
- 6 размеров ячеек: 1K / 4K / 16K / 64K / 256K / 1M предметов на стойку
- Сортировка по имени, количеству, порядку контейнера или ID
- Блокировка стойки за владельцем и добавление доверенных игроков
- Ввод/вывод через воронки с настраиваемой скоростью и Speed Upgrade

**Mesh-сеть**
- Покрытие — это реальный **куб** в мире вокруг каждого узла, а не абстрактное «число радиуса», которое нужно угадывать
- Стойки (Server Rack) якорят сеть (зона 16 блоков), Wireless Router расширяют её (зона 64 блока)
- Роутеры должны пересекаться с существующей зоной, чтобы подключиться, — сеть растёт от стойки наружу так, как вы строите
- Путь от каждого роутера до стойки пересобирается с нуля при каждой проверке (BFS) — это настоящая mesh, а не жёсткая цепочка
- Самовосстановление: если у роутера есть запасной путь до стойки, сеть переключается на него автоматически при потере узла. Дублируйте роутеры и избегайте одиночных «мостов»
- Один Server Rack = одна сеть — соседние стойки независимы и не объединяются
- Оба радиуса настраиваются в конфиге (`rack-range`, `router-range`)

**Терминалы**
- **Wall Terminal** — настенный доступ на месте для комнат-хранилищ
- **Wireless Terminal** — привяжите модулем связи и достаньте хранилище из любой точки mesh-сети

**Пользовательские рецепты**
- Крафтите снаряжение Enigma на особом верстаке (раздатчик)
- Просматривайте каждый рецепт в игровой книге рецептов с постраничной навигацией

**Языки**
- В комплекте: ru, en, de, fr, es, pl, cn
- Бросьте `.json` в папку `languages/` и укажите его в конфиге, чтобы добавить свой

**Интеграция с WorldGuard** *(опционально)*
- Soft-зависимость — работает и без неё, ошибок нет, если WorldGuard не установлен
- Блокирует установку, поломку, привязку терминалов и доступ к хранилищу в защищённых регионах
- Участники и владельцы региона всегда имеют доступ, посторонним отказано
- Доступ к хранилищу проверяется по координате **стойки**, а не игрока — терминал не дотянется до стойки в чужом защищённом регионе
- Кастомный флаг региона `enigma-storage-use` для тонкой настройки: `/rg flag <регион> enigma-storage-use deny` (без флага — проверка по членству в регионе)
- Дружит с GriefPrevention, Towny, Lands и подобными — создание Sorter тоже учитывает их защиту блоков
- По умолчанию работает по принципу **fail closed** — сбой проверки WorldGuard запрещает доступ, а не молча пропускает грифера

## Установка

1. Поместите `EnigmaStorage.jar` в папку `plugins/`.
2. Запустите сервер.
3. Настройте `plugins/EnigmaStorage/config.yml` по вкусу.

Есть опциональный ресурс-пак — игроки видят ссылку для скачивания при входе (отключается в конфиге).

## Команды

Все команды используют `/es` — также работают алиасы `/enigmastorage` и `/dsu`.

| Команда | Что делает |
|---|---|
| `/es help` | Показать список команд |
| `/es book` | Открыть книгу рецептов |
| `/es give <предмет> [кол-во]` | Выдать предмет себе |
| `/es give <игрок> <предмет> [кол-во]` | Выдать предмет игроку |
| `/es items [страница]` | Список всех ключей предметов плагина |
| `/es craft <рецепт> [кол-во]` | Выдать себе результат рецепта |
| `/es craft <игрок> <рецепт> [кол-во]` | Выдать игроку результат рецепта |
| `/es recipes [страница]` | Список всех имён рецептов |
| `/es migrate` | Запустить одноразовую миграцию данных SQLite → NBT |
| `/es reload` | Перезагрузить конфиг и языковые файлы |

Ключи предметов для `/es give`: `server_rack`, `router`, `wall_terminal`, `terminal`, `link_module`, `receiver`, `sorter_wrench`, `speed_upgrade`, `creative_storage_container`, а также семейства `storage_cell_*` / `storage_container_*`.

## Права

Указанные ниже права для игроков по умолчанию выданы всем, чтобы можно было строить «из коробки», остальные по умолчанию `op`.

| Право | Что разрешает | По умолчанию |
|---|---|---|
| `enigmastorage.use` | Использовать `/es` вообще | **все** |
| `enigmastorage.create` | Создавать стойки (Server Rack) | **все** |
| `enigmastorage.wireless` | Использовать беспроводной терминал | **все** |
| `enigmastorage.wallterminal` | Открывать настенный терминал | **все** |
| `enigmastorage.recipe` | Доступ к рецептам `/es` | **все** |
| `enigmastorage.recipe.book` | Открывать книгу рецептов (`/es book`) | **все** |
| `enigmastorage.recipe.craft` | Крафтить пользовательские рецепты на верстаке | **все** |
| `enigmastorage.recipe.craft.<name>` | Крафтить один конкретный рецепт | **все** |
| `enigmastorage.adminopen` | Открывать заблокированные DSU | op |
| `enigmastorage.give` | `/es give` и `/es items` | op |
| `enigmastorage.migrate` | Запускать `/es migrate` | op |
| `enigmastorage.reload` | Запускать `/es reload` | op |
| `enigmastorage.recipe.giveitem` | Получать предметы ПКМ по книге рецептов | op |
| `enigmastorage.recipe.give` | `/es craft` и `/es recipes` | op |
| `enigmastorage.recipe.craftall` | Крафтить всё без отдельных прав на рецепты | op |
| `enigmastorage.recipe.new` | Создавать новые рецепты через книгу рецептов | op |
| `enigmastorage.recipe.op` | Видеть имя права у каждого рецепта в книге | op |

## Конфиг

```yaml
loadresourcepack: true   # показывать ссылку на ресурс-пак при входе
resourcepackmessage: true
prefix: "&f&l[&9&lEnigmaStorage&f&l]"
range: 500               # устаревший радиус беспроводного терминала в блоках (-1 = без ограничения)

# Покрытие mesh-сети (радиус куба по каждой оси, в блоках)
rack-range: 16           # базовая зона Server Rack
router-range: 64         # зона Wireless Router (должна пересекаться с существующей зоной)

# URL для скачивания ресурс-пака
resourcepack:
  url: "https://cdn.ltht.app/EnigmaNorth/EnigmaStorage-v1010.zip"

language: "en"           # en, ru, de, fr, es, pl, cn — или кастомный файл в languages/

# Анти-гриф WorldGuard (опционально)
worldguard:
  enabled: true
  protect-build: true    # защита установки/поломки блоков Enigma
  protect-access: true   # защита открытия GUI, апгрейдов, привязки терминалов, hopper I/O
  fail-open: false       # false = запрет при внутренней ошибке WG (рекомендуется)

# Лимиты хранилища (применяются в момент крафта)
countinstacks: false     # считать лимиты в стаках, а не в отдельных предметах
1kmax: 1
4kmax: 4
16kmax: 16
64kmax: 64
256kmax: 256
1mmax: 1024
```
